# Knowledge Intel

Standalone static microsite for Knowledge Intelligence.

## Files

- `index.html` - single-page static site.
- `CNAME` - GitHub Pages custom domain configuration for `knowledge-intel.com`.
- `.nojekyll` - bypasses Jekyll processing for a plain static deployment.

## Deployment

Deploy via GitHub Pages from the repository root. DNS for `knowledge-intel.com` should point to GitHub Pages after the repository is published and Pages is enabled.
